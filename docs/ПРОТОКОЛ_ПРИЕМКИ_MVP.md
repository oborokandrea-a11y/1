# Протокол технической приёмки MVP «Цифра»

**Дата:** 22.11.2026 · **Объект:** рабочее веб-приложение документооборота производственной практики · **Метод:** автоматизированные интеграционные тесты (FastAPI TestClient + изолированная SQLite-БД).

## Сверка с чек-листом третьего спринта

| Критерий | Реализация | Проверка |
|---|---|---|

## Итог реального прогона

`pytest -q --disable-warnings`: **4 passed**.

Проверены положительные и отрицательные сценарии: подача, загрузка, смена статуса, двухсторонний маршрут, версия 2, CSRF, доступ чужого студента, кабинет предприятия, задачи и аналитика. После обнаруженной ошибки интерфейса для статуса `REVISION_REQUIRED` шаблон исправлен и повторно испытан.

## Что не подтверждает тестирование

- Факт публикации приложения в интернете и доступность его с внешней сети.
- Юридически значимое подписание/УКЭП или интеграцию с действующим университетским ЭДО.
- Безопасность на уровне независимого пентеста, проверку политик персональных данных и устойчивость при большой нагрузке.
- Измеренный эффект на реальных пользователях «после». Он появится только после пилотных обращений по сопоставимой методике.

**Решение:** рабочий исследовательский MVP готов к локальной демонстрации. Для общедоступного deployment необходимо подключить защищённую БД, приватное файловое хранилище, HTTPS, домен и провести внешнюю проверку безопасности.

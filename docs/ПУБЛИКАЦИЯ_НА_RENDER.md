# Публичный запуск «Цифра» — FastAPI + Render

## Что получает пользователь

Публичный HTTPS-адрес вида `https://<ваше-имя>.onrender.com`; страница входа доступна из интернета. Личные кабинеты и файлы закрыты паролями, права проверяются сервером. Данные заявок, вложения и журнал сохраняются в SQLite на отдельном постоянном диске. Подписания в интерфейсе — внутренние подтверждения, **не УКЭП**.

## Первоначальные действия

1. Создать репозиторий GitHub (желательно **Private**), загрузить содержимое архива «Цифра_MVP_для_Render.zip» в корень. Никогда не добавлять `.env`, `demo_credentials.txt`, `local.sqlite3`, `private_uploads/` и реальные договоры.
2. Открыть https://dashboard.render.com/blueprints и создать Blueprint из связанного GitHub-репозитория. Конфигурация берётся из `render.yaml`.
3. В процессе создания заполнить скрытые `INITIAL_ADMIN_USERNAME` (например, `manager.cifra`) и `INITIAL_ADMIN_PASSWORD` (сильный уникальный пароль не менее 12 символов с буквами обоих регистров и цифрами). Пароль вводить **только в Render**, не в ChatGPT и не в репозиторий. Render сгенерирует `SECRET_KEY`.
4. При запуске предусмотрен один платный web service **Starter** с постоянным диском 1 ГБ; проверьте актуальную стоимость в интерфейсе перед подтверждением. Бесплатный тариф без диска **не подходит** для хранения документов.
5. После статусa Live открыть присвоенную ссылку HTTPS и войти как менеджер. Через раздел «Команда» создать отдельные тестовые аккаунты студента, сотрудника, ответственного по практике и отдела практик. Партнёры создают свои реквизиты по одноразовому приглашению для конкретного договора.
6. Проверить `/health`, затем рабочий сценарий: вход студента → создание договора → загрузка файла → отправка → подтверждения по ролям → журнал действий → задачи и сроки. После успешного создания администратора можно удалить `INITIAL_ADMIN_PASSWORD` из Render Environment: текущий аккаунт сохранится на диске.

## Данные и ограничения

- Все реальные пользовательские документы хранить только после согласования политики персональных данных, полномочий и условий размещения. До этого использовать обезличенные примеры.
- Для production с повышенными требованиями к доступности заменить SQLite на управляемый PostgreSQL, а локальную файловую систему — на закрытое объектное хранилище, настроить бэкапы, мониторинг, аудит безопасности и корпоративную систему учётных записей.
- Привязать свою доменную зону можно через Render; её имя требуется добавить в `ALLOWED_HOSTS`.
- Запись `render.yaml` не является фактом уже запущенного сервиса. Публичный адрес появится только в Render после авторизованного развёртывания.
